# 정답 테스트와 실제 실행 결과

이 문서는 **우리가 넣은 버그가 실제로 발생했는지, 제품이 준 수정 코드가 정말 고쳤는지 확인한 기록**이야.

## 먼저 알아둘 것

`test_pilot_oracle.py`
= 제품에 보여주지 않고 미리 준비한 정답 테스트 6개

`test_posthoc_p04.py`
= 리뷰가 끝난 뒤 P04의 다른 문제를 확인하려고 추가한 테스트 1개

## 버그의 원본

| 시험 | 실제 Flask 기록 | 확인할 문제 |
|---|---|---|
| P01 | [Flask PR #6096](https://github.com/pallets/flask/pull/6096), [이슈 #6093](https://github.com/pallets/flask/issues/6093) | IPv6 서버 주소 처리 |
| P02 | [Flask PR #5928](https://github.com/pallets/flask/pull/5928) | 종료 중 오류가 나도 마지막 신호를 보내는가 |
| P03 | [Flask PR #5917](https://github.com/pallets/flask/pull/5917), [이슈 #5916](https://github.com/pallets/flask/issues/5916) | 사용자가 직접 켠 OPTIONS 설정을 지키는가 |
| P04 | [Flask PR #6013](https://github.com/pallets/flask/pull/6013) | 파일 확장자의 대문자·소문자를 모두 처리하는가 |

## 정상 코드 확인

버그를 넣기 전 정상 코드에서는 모두 통과했어.

```text
제품에 안 보여준 정답 테스트 6개 통과
누구나 볼 수 있는 기존 테스트 493개 통과
```

## 버그를 넣은 코드 확인

| 시험 코드 | 기존 테스트 | 정답 테스트가 보여준 결과 |
|---|---|---|
| P01 | 133개 통과 | IPv6 서버 주소 버그가 실제로 나타남 |
| P02 | 22개 통과 | 마지막 종료 신호가 사라지는 버그가 실제로 나타남 |
| P03 | 133개 통과 | OPTIONS 설정이 무시되는 버그가 실제로 나타남 |
| P04 | 32개 통과 | 대소문자 파일 안전 처리 버그 3개가 실제로 나타남 |
| C01 | 32개 통과 | 버그 없음, 정답 테스트 6개 통과 |
| C02 | 133개 통과 | 버그 없음, 정답 테스트 6개 통과 |

여기서 P01~P04의 정답 테스트가 실패한 것은 나쁜 결과가 아니야.

우리가 일부러 넣은 버그가 정말 발생했다는 증거야.

## CodeRabbit의 수정 코드 확인

P03 수정 코드:

```text
P03 정답 테스트 통과
기존 테스트 493개 통과
결론: 완전히 고침
```

P04 수정 코드:

```text
대소문자 정답 테스트 3개 통과
기존 테스트 493개 통과
점으로 시작하는 파일 추가 테스트 실패
결론: 처음 찾은 문제만 고치고 다른 문제는 남김
```

## 다음 실험에서 다시 쓰면 안 되는 이유

이 정답 테스트는 이제 공개됐어.

Qodo와 CodeRabbit이 다음에는 정답을 미리 볼 수 있으므로 같은 코드를 다시 시험 문제로 쓰면 안 돼. 다음 시험에서는 같은 원리라도 코드 모양과 입력값을 바꿔야 해.

딱 기억해.

**P01~P04에서 테스트가 실패한 것은 버그가 실제로 발생했다는 뜻이고, C01~C02가 통과한 것은 정상 코드라는 뜻이야.**
