# 01. 시험 대상과 범위 — 무엇을 비교하는지 헷갈리지 않으려고

## 한 문장으로

**Flask의 실제 과거 문제를 시험지로 삼아 Qodo와 CodeRabbit의 PR 리뷰 능력을 비교한다.**

## 각자의 역할

| 대상 | 역할 |
|---|---|
| Flask | 실제 문제와 수정 기록을 주는 시험 재료 |
| Qodo | 같은 코드를 리뷰하는 첫 번째 제품 |
| CodeRabbit | 같은 코드를 리뷰하는 두 번째 제품 |
| 제품에 안 보여주는 정답 테스트 | 제품의 말과 수정 코드가 맞는지 확인하는 장치 |
| SH Solution | 두 제품이 반복해서 놓친 빈틈을 검증할 앞으로의 제품 |

이 표로 Flask와 두 리뷰 제품을 서로 비교 대상으로 잘못 보는 일을 막을 수 있어.

## 첫 본시험의 범위

- 언어: Python
- 프로젝트: Flask
- 리뷰 대상: GitHub Pull Request
- 설정: 제품별 기본 설정
- 이번 문제: 버그 4개, 정상 코드 2개
- 전체 PR: 12개
- 제외: 기존 예비시험 P01~P04와 C01~C02
- 한계: 현재 저장소에 정답 단서가 있어 내부 비교로만 사용

## 지금 말할 수 있는 것

Flask 코드에서 실제로 다시 만든 문제를 두 제품이 얼마나 잘 찾았는지는 말할 수 있어.

## 아직 말할 수 없는 것

- 모든 Python 프로젝트에서도 같은 결과가 난다.
- JavaScript나 Go에서도 같은 결과가 난다.
- 한 제품이 언제나 다른 제품보다 낫다.
- SH Solution이 이미 두 제품보다 뛰어나다.

이런 말은 Express와 chi 같은 다른 프로젝트까지 따로 시험한 뒤에만 검토한다.

딱 기억해.

**Flask는 시험지이고, Qodo와 CodeRabbit이 시험을 보는 제품이야.**
