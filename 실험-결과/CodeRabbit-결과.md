# CodeRabbit 실험 결과

이 문서는 **CodeRabbit이 어떤 버그를 찾았고, 제안한 수정 코드가 실제로 작동했는지 쉽게 설명하는 결과지**야.

## 10초 결론

- 버그 4개 중 3개를 제대로 찾았어.
- 정상 코드 2개에는 잘못된 경고를 하지 않았어.
- P03과 P04에는 바로 적용할 수 있는 코드 수정안을 줬어.
- P03은 완전히 고쳤지만 P04는 일부 문제만 고쳤어.

## 전체 결과

| 시험 | 실제 상태 | CodeRabbit 결과 | 걸린 시간 | 코드 수정안 |
|---|---|---|---:|---|
| P01 | 버그 있음 | 찾음 | 219초 | 없음 |
| P02 | 버그 있음 | 핵심 문제는 못 찾고 다른 문제를 찾음 | 110초 | 없음 |
| P03 | 버그 있음 | 찾음 | 118초 | 완전히 고침 |
| P04 | 버그 있음 | 찾음 | 142초 | 일부만 고침 |
| C01 | 정상 코드 | 잘못된 경고 없음 | 86초 | 필요 없음 |
| C02 | 정상 코드 | 잘못된 경고 없음 | 310초 | 필요 없음 |

버그를 제대로 찾은 P01·P03·P04의 가운데 시간은 142초야.

## P01: IPv6 서버 주소 문제

```text
IPv6 주소 입력
↓
주소를 첫 번째 콜론에서 잘못 자름
↓
포트 번호를 숫자로 바꾸지 못함
↓
서버가 시작되지 않음
```

CodeRabbit은 원인, 문제가 생기는 입력, 최종 결과를 모두 맞혔어.

- [CodeRabbit이 남긴 실제 댓글](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6#discussion_r3921166594)

## P02: 종료 신호가 빠지는 문제

버그가 들어간 코드는 프로그램 종료 중 오류가 나면 마지막 종료 신호를 보내기 전에 멈췄어.

CodeRabbit은 이 핵심 문제를 못 찾았어.

대신 마지막 종료 신호를 받는 코드에서 또 오류가 나면 그 오류가 사라지는 다른 문제를 찾았어. Qodo가 찾은 다른 문제와 같아.

- [CodeRabbit이 찾은 다른 문제](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/7#discussion_r3921178460)

## P03: 사용자가 직접 켠 설정이 무시되는 문제

CodeRabbit은 사용자가 직접 켠 OPTIONS 설정이 무시되어 405 오류가 생기는 문제를 찾았어.

그리고 코드 두 줄을 올바른 위치로 옮기는 수정안도 줬어.

```text
CodeRabbit의 수정 코드 적용
↓
이 버그를 확인하는 정답 테스트 통과
↓
기존 테스트 493개 통과
↓
완전히 고친 것으로 확인
```

- [문제 설명과 코드 수정안](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/8#discussion_r3921195653)

## P04: 대문자가 섞인 파일의 안전 처리 문제

CodeRabbit은 대문자가 섞인 HTML 파일에서 안전 처리가 꺼지는 문제를 찾았어.

확장자를 소문자로 바꾼 뒤 비교하는 코드 수정안도 줬어.

```text
CodeRabbit의 수정 코드 적용
↓
대소문자 문제를 확인하는 정답 테스트 3개 통과
↓
기존 테스트 493개 통과
↓
다른 파일 이름을 확인하는 추가 테스트는 실패
```

즉 처음 찾은 대소문자 문제는 고쳤지만, `.html`처럼 이름이 점으로 시작하는 파일 문제는 남았어.

- [문제 설명과 코드 수정안](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/9#discussion_r3921222648)

## 누가 테스트했나

CodeRabbit이 스스로 수정 코드를 적용하고 테스트한 것은 아니야.

```text
CodeRabbit이 코드 수정안 제공
↓
우리가 별도 코드에 직접 적용
↓
우리가 정답 테스트와 기존 테스트 실행
↓
완전히 고쳤는지 확인
```

## 이번 결과로 말할 수 없는 것

- 시험이 6개뿐이라 CodeRabbit이 항상 더 좋거나 느리다고 말할 수 없어.
- P02에는 서로 다른 문제가 두 개 섞여 있었어.
- P04 수정안은 처음 정한 문제는 고쳤지만 모든 문제를 고치지는 못했어.

딱 기억해.

**CodeRabbit은 버그 세 개를 찾고 코드 수정안 두 개를 줬지만, 그중 하나는 일부 문제만 고쳤어.**
