## 확인한 조건

- 같은 문제의 두 PR은 같은 base, 같은 head 커밋, 같은 파일, 같은 diff 지문을 썼다.
- PR을 만들 때 제목과 사람이 쓴 본문은 쌍마다 같고 중립적이었다. 원본 이슈 번호, 정답 설명, 숨은 테스트를 넣지 않았다.
- 정답 테스트는 Git 저장소 밖에 보관했다. 정상 코드 3/3 통과, 결함 코드 0/3 통과를 제품 실행 전에 확인했다.
- 공개 전체 테스트는 모든 문제에서 통과했다. 통과 수 차이는 정답 단서가 되는 기존 테스트를 각 base에서 제거했기 때문이다.
- 문제마다 먼저 부르는 제품을 번갈아 배정했다. Qodo 선행 13개, CodeRabbit 선행 12개다.
- 리뷰 중 사람이 정답이나 수정 코드를 댓글로 주지 않았고 PR head도 바꾸지 않았다.

## 생긴 일과 처리

| 일 | 점수 처리 |
|---|---|
| Qodo PR에 CodeRabbit의 ‘자동 리뷰 꺼짐’ 안내가 자동 생성됨 | 코드 판단이 아니므로 무시. 상대 제품의 정답 노출 없음 |
| 모든 PR에 Copilot 사용량 초과 안내가 자동 생성됨 | 리뷰 내용이 아니므로 무시 |
