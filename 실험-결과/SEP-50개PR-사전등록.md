이 문서는 제품 리뷰를 보기 전에 문제 25개와 판정 기준을 고정하는 비공개 기록이다.

## 실험 범위

```text
새 결함 16개
↓
정상 변경 5개
↓
같은 원리를 다른 코드 모양으로 만든 반복 문제 4개
↓
각 문제를 두 제품에 한 번씩 보냄
↓
PR 50개
```

- 실행 저장소: `seonho12-54/qodo-coderabbit-benchmark`
- 비교 방식: 같은 저장소 안에서 같은 base와 같은 head 커밋을 쓰는 쌍둥이 PR
- 한계: 저장소 이름과 기본 브랜치에 과거 실험 자료가 있으므로 완전한 블라인드 시험이 아니다.
- 제품 분리: `.pr_agent.toml`의 자동 명령과 `.coderabbit.yaml`의 자동 리뷰를 끄고 PR 댓글로 한 제품만 부른다.
- Qodo 명령: `/agentic_review`
- CodeRabbit 명령: `@coderabbitai full review`
- CodeRabbit 사용량: 2026-09-04 확인 시 리뷰 가능
- Qodo 사용량: 포털 로그인이 없어 남은 월 횟수는 직접 확인하지 못했다. 첫 묶음에서 실행 응답으로 확인한다.


## 실행 뒤 편차 기록

아래 내용은 리뷰를 본 뒤 사전 분류를 바꾼 것이 아니라, 계획과 실제 실행의 차이를 남기는 사후 기록이다.

- 사전 크기 8/10/7은 유지했지만 실제 diff는 1~87줄이었다. 크기별 결과는 줄 수 효과의 확정 근거로 쓰지 않는다.
- CodeRabbit이 자기 PR 본문에 release-note 요약을 자동으로 붙였다. 사람 입력은 같았지만 최종 본문은 달라졌으므로 end-to-end 제품 비교로만 해석한다.
- Qodo SEP-007은 원본 Flask PR #4230, CodeRabbit SEP-023은 원본 이슈 #6093을 찾아 언급했다. 인터넷을 차단한 추론-only 시험이 아니다.
- 같은 작업자가 문제 구성과 판정을 맡았다. 제품 출력 JSON을 먼저 고정했지만 독립 심사자 이중 블라인드는 아니다.
- CodeRabbit 시간당 포함 리뷰 제한은 실패로 세지 않고 같은 PR에서 재시도했다. 첫 요청 기준 지연에는 제한 대기를 포함했다.
