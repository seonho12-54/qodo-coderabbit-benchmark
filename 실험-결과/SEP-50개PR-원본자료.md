# SEP 50개 PR 원본 자료

각 제품·문제 폴더에는 아래 여덟 파일이 있다.

- `pr.json`: PR 본문, 커밋, 파일, 댓글, 리뷰, 검사 요약
- `diff.patch`: 실제 변경
- `issue-comments.json`: 일반 댓글과 제품 요약
- `review-comments.json`: 줄 단위 리뷰
- `reviews.json`: GitHub review 객체
- `check-runs.json`: commit 검사
- `workflow-runs.json`: workflow 실행
- `metadata.json`: head SHA와 diff SHA-256

`scores.json`, `blind-findings.json`, `statistics.json`은 각각 봉인 정답 대조 점수, 제품 출력 추출본, 재현 가능한 계산 결과다. `sep012-coderabbit-verification.md`는 유일한 제품 patch의 적용·테스트 기록이다.
