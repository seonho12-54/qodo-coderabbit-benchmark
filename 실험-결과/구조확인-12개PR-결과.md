## B01: 종료 함수가 중간에 멈춤

실제 Flask [수정 PR #5928](https://github.com/pallets/flask/pull/5928)을 바탕으로 만들었다.

```text
종료 함수 하나에서 오류 발생
↓
반복문 전체가 끝남
↓
뒤에 남은 종료 함수가 실행되지 않음
```

- 정상 코드: 숨은 확인 통과
- 결함 코드: 뒤 종료 함수가 실행되지 않아 실패
- Qodo: [문제 발견](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6180#discussion_r3921929052)
- CodeRabbit: [문제와 적용 가능한 수정 코드 제공](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6181#discussion_r3921933519)
- CodeRabbit 수정 코드: 별도 코드에 적용한 뒤 숨은 확인 통과

## B02: 비밀 키를 바꾸면 기존 사용자가 로그아웃됨

실제 Flask [수정 PR #5632](https://github.com/pallets/flask/pull/5632)을 바탕으로 만들었다.

```text
서비스가 비밀 키를 새것으로 교체
↓
이전 키를 보조 키로 설정
↓
코드가 보조 키를 무시
↓
기존 로그인 세션을 읽지 못해 사용자가 로그아웃됨
```

- 정상 코드: 숨은 확인 통과
- 결함 코드: 이전 세션을 읽지 못해 실패
- Qodo: [원인·조건·로그아웃 결과까지 발견](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6194#discussion_r3922065171)
- CodeRabbit: [고칠 문제 없다고 판단](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6195#issuecomment-5522055051)

## B03: 설정된 서버 이름이 다른 호스트의 정상 라우팅을 막음

실제 Flask [수정 PR #5634](https://github.com/pallets/flask/pull/5634)을 바탕으로 만들었다.

```text
SERVER_NAME이 설정됨
↓
실제 요청 호스트 대신 설정값으로 주소를 찾음
↓
정상 주소가 404로 끝남
```

- 정상 코드: 숨은 확인 통과
- 결함 코드: 정상 요청이 404가 되어 실패
- Qodo: [서로 연결된 두 원인을 모두 발견](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6196#discussion_r3922062230)

## B04: 믿지 않는 Host 요청을 막지 않음

실제 Flask [수정 PR #5637](https://github.com/pallets/flask/pull/5637)을 바탕으로 만들었다.

```text
허용할 호스트를 설정
↓
코드가 설정을 적용하지 않음
↓
허용하지 않은 Host 요청도 통과
↓
Host 값을 이용한 주소와 이동 응답이 조작될 수 있음
```

- 정상 코드: 숨은 확인 통과
- 결함 코드: 허용하지 않은 요청이 400이 아니라 정상 처리되어 실패
- Qodo: [보안 영향까지 발견](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6198#discussion_r3922065713)
