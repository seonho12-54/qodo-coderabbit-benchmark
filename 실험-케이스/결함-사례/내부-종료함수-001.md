# 내부 비교 001: 종료 함수가 중간에 멈추는 문제

> 이 시험은 완전한 블라인드 시험이 아니다. 이 저장소에 과거 정답 자료가 있으므로 **내부 비교 결과**로만 사용한다.

## 실제 문제의 출처

- Flask 수정 PR: [pallets/flask #5928](https://github.com/pallets/flask/pull/5928)
- 실제 수정 내용: 종료 함수 하나가 실패해도 나머지 종료 함수를 모두 실행한 뒤, 모아 둔 오류를 마지막에 전달한다.

## 이번에 넣은 문제

```text
종료 함수 여러 개가 등록됨
↓
먼저 실행된 종료 함수에서 오류가 남
↓
반복문 전체가 끝나 버림
↓
뒤에 남은 종료 함수가 실행되지 않음
```

코드 변경은 한 곳뿐이다. 각 종료 함수를 따로 감싸던 오류 수집기를 반복문 전체에 한 번만 씌웠다.
