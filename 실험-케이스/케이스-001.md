## PR 요구사항

서버 실행 설정에서 호스트와 포트를 읽는 코드를 더 단순한 흐름으로 정리한다.

다음 동작은 유지되어야 한다.

- `SERVER_NAME`이 없을 때 기존 기본 호스트와 포트를 사용한다.
- 호출자가 `host` 또는 `port`를 직접 넘기면 그 값이 우선한다.
- `SERVER_NAME`에 호스트와 포트가 있으면 서버 실행 인자로 전달한다.
- 기존 공개 테스트가 모두 통과한다.

## 리뷰 제품이 해야 할 일

