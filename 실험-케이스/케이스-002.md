# P02: 종료 신호가 사라지는 문제

> 예비시험 사례야. 본시험 점수에는 넣지 않아.

이 문서는 **두 번째 버그 시험에서 두 제품이 함께 놓친 문제를 설명하는 문서**야.

## 시험에 사용한 PR

| 제품 | PR |
|---|---|
| Qodo | [#6175](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6175) |
| CodeRabbit | [#7](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/7) |

두 PR에는 똑같은 코드 변경이 들어 있어.

## 어떤 코드를 바꿨나

Flask가 프로그램을 종료하면서 오류를 처리하는 순서를 바꿨어.

## 우리가 찾으라고 넣은 핵심 버그

정상 흐름:

```text
종료 정리 중 오류 발생
↓
그래도 마지막 종료 신호 전송
↓
그다음 오류를 밖으로 전달
```

버그가 들어간 흐름:

```text
종료 정리 중 오류 발생
↓
바로 오류를 밖으로 전달
↓
마지막 종료 신호가 사라짐
```

마지막 신호를 기다리던 다른 코드가 실행되지 않는 게 핵심 문제야.

이 문제는 실제 Flask [수정 PR #5928](https://github.com/pallets/flask/pull/5928)을 바탕으로 만들었어.

## 테스트 결과

| 확인한 것 | 결과 |
|---|---|
| 누구나 볼 수 있는 기존 테스트 | 22개 통과 |
| 제품에 안 보여준 정답 테스트 | 마지막 종료 신호가 사라지는 버그가 실제로 나타남 |

## 제품 결과

| 제품 | 우리가 넣은 핵심 버그 | 같은 코드에 섞인 다른 버그 |
|---|---|---|
| Qodo | 못 찾음 | 찾음 |
| CodeRabbit | 못 찾음 | 찾음 |

두 제품은 마지막 종료 신호 자체가 사라지는 문제를 못 찾았어.

대신 마지막 종료 신호를 받은 코드가 오류를 내면 그 오류가 사라지는 다른 문제를 둘 다 찾았어.

- [Qodo가 찾은 다른 문제](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6175#discussion_r3921175042)
- [CodeRabbit이 찾은 다른 문제](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/7#discussion_r3921178460)
