# P03: 사용자가 직접 켠 설정이 무시되는 문제

이 문서는 **세 번째 버그 시험의 내용과 결과를 설명하는 문서**야.

## 시험에 사용한 PR

| 제품 | PR |
|---|---|
| Qodo | [#6176](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/6176) |
| CodeRabbit | [#8](https://github.com/seonho12-54/qodo-coderabbit-benchmark/pull/8) |

두 PR에는 똑같은 코드 변경이 들어 있어.

## 실제 버그

```text
전체 기본 설정에서는 OPTIONS 기능을 끔
↓
사용자가 특정 주소에서만 OPTIONS 기능을 직접 켬
↓
코드가 사용자의 선택을 무시함
↓
OPTIONS 요청이 405 오류로 끝남
```

이 문제는 실제 Flask [이슈 #5916](https://github.com/pallets/flask/issues/5916)과 [수정 PR #5917](https://github.com/pallets/flask/pull/5917)을 바탕으로 만들었어.

## 결과

| 확인한 것 | 결과 |
|---|---|
| 누구나 볼 수 있는 기존 테스트 | 133개 통과 |
| 제품에 안 보여준 정답 테스트 | 설정이 무시되는 버그가 실제로 나타남 |
| Qodo | 버그를 찾음, 61초 |
| CodeRabbit | 버그를 찾음, 118초 |
| CodeRabbit 수정 코드 | 정답 테스트와 기존 테스트 493개 모두 통과 |
